# /constructra reload

!!! tip "Permissions"
    This command needs permission level 2 or higher by default. This can be [configured](../../../../users/configuration/server-config.md).

## Summary
Reloads the server-side config (`/run/config/constructra-server.json5`), some changes may not be applied, and instead need a full server restart.

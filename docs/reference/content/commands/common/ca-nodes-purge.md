# /constructra nodes purge

!!! tip "Permissions"
    This command needs permission level 4 or higher by default. This can be [configured](../../../../users/configuration/server-config.md).

## Summary
Purges (removes) all ResourceNodes from the world and the network according to the parameters given.  
It will spit the removed Nodes and their positions into chat, shared to other ops.

!!! danger
    This is a dangerous command, it can break your progression!

## Parameters
- `pos`: The position where the {==centre==} of the search should be.
- `range`: The {==range from the centre==} (`pos`) of the search. :material-plus-circle-multiple-outline:
- `destroy_blocks`: Whether to also {==destroy any of the blocks==} that the Node contained. :material-plus-circle-multiple-outline:

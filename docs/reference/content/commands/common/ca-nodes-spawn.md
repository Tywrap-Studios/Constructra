# /constructra nodes spawn

!!! tip "Permissions"
    This command needs permission level 2 or higher by default. This can be [configured](../../../../users/configuration/server-config.md).

## Summary
Spawns a new ResourceNode in the world and adds it to the network, particularly handy if you accidentally broke a Node or if your natural generation turned out :fontawesome-solid-poop:.

## Parameters
- `pos`: The position at which to place the {==centre==} of the Node.
- `type`: What the Resource of the Node should be, the format is `namespace:path` as it's {==registry==} driven.
- `obstructed`: Whether the Node should be {==obstructed==} (true) or not (false).
